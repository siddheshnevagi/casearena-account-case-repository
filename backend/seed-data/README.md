# Seed data

`sample-profitability-case.pdf` is a small, original practice case (not
sourced from any published casebook) for exercising the upload flow
end-to-end — US-04B's acceptance criteria, and a quick way to get
something real into the repository without hunting for a PDF on your own
machine.

**Use it to test the upload flow:**
- Title: `BrightBrew Coffee Co. — Profitability Decline`
- Case type: `PROFITABILITY`
- Difficulty: `MEDIUM`
- Industry: `Retail` (or leave blank)

This is **not** the "at least 25 curated cases" launch-seed content called
for in the PRD (§9) — that's a real content-curation task for the team,
not something to fake with placeholder PDFs. This one file exists purely
so upload/browse/search/share can be tested without first solving "where
do I get a PDF."
